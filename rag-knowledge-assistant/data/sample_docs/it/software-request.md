# Software Requests and Licensing (IT-KB-040)

Request software through the "Software Request" form in the ServiceDesk portal. Only software in the approved catalog can be installed on company devices.

## Approval Matrix

| Software | Who can request | Approval needed | Monthly charge to cost center |
| --- | --- | --- | --- |
| Slack, Zoom, Microsoft 365 | Everyone | None (pre-installed) | $0 |
| Tableau Creator | Everyone | Manager approval | $70 |
| Tableau Viewer | Everyone | None | $15 |
| JetBrains IntelliJ IDEA | Engineering | Engineering manager approval | $50 |
| Figma Professional | Design and Product | Design lead approval | $20 |

## Unapproved Software

Software not in the catalog requires a security review, which takes about 10 business days. Browser extensions are subject to the same review.
