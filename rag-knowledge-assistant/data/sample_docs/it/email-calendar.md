# Email, Calendar and Shared Mailboxes (IT-KB-011)

## Mailbox Size

Mailboxes have a 100 GB quota. Email older than 3 years is moved to the online archive automatically.

## Shared Mailboxes

Request a shared mailbox in the ServiceDesk portal. Each shared mailbox needs a named owner who approves access requests.

## Out-of-Office

Set an automatic reply in Outlook under File > Automatic Replies for absences longer than one day.
