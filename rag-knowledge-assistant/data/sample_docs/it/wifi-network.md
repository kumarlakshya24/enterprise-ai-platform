# Office Wi-Fi Networks (IT-KB-008)

## Networks

Company laptops connect automatically to the "Lumen-Corp" network using certificate authentication. Personal devices must use "Lumen-Guest", which is isolated from internal systems.

## Guest Access

Visitors receive a daily guest Wi-Fi code from reception. The code changes every day at midnight.

## Troubleshooting

If a company laptop cannot join Lumen-Corp, forget the network and restart; if that fails, the device certificate may need renewal through Company Portal.
