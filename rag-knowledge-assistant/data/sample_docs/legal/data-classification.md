# Data Classification and Handling Policy (SEC-POL-002)

## Classification Levels

| Level | Examples | Handling |
| --- | --- | --- |
| Public | Marketing site, press releases | No restrictions |
| Internal | Policies, org charts | Share only with employees |
| Confidential | Financial results before release, contracts | Need-to-know, encrypted at rest |
| Restricted | Customer PII, credentials, salary data | Named access only, never leave approved systems |

## AI Tools

Restricted data must never be pasted into external AI tools or chatbots. Confidential data may only be used with AI tools approved by Security.

## Reporting Mishandling

Suspected mishandling of Confidential or Restricted data must be reported to the Security team immediately.
