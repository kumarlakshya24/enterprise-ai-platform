# Open Source Software Policy (LEG-POL-040)

## Allowed Licenses

MIT, Apache-2.0 and BSD-licensed dependencies may be used without review.

## Restricted Licenses

GPL and AGPL dependencies require Legal review before they are added to any distributed product.

## Contributing

Contributing to external open source projects requires approval from your engineering manager and must not include proprietary code.
