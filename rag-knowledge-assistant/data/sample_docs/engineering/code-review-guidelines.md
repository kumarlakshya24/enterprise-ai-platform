# Code Review Guidelines (ENG-STD-004)

## Approvals

Changes to production services require 2 approvals, at least one from a CODEOWNERS member of the affected service.

## Pull Request Size

Keep pull requests under 400 changed lines. Larger changes should be split or reviewed in a design review first.

## Review Turnaround

Reviewers should respond within one business day.
